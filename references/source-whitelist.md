# 信源白名单（权威信源分级与审核规则）

本文件定义 storm-report 报告**唯一允许引用**的信源范围。阶段 3 深度检索的每一步都必须按此过滤，凡白名单外的来源一律不得进入证据库。

## 一、信源分级

| 级别 | 类型 | 说明 |
|---|---|---|
| **A 级**（最高） | 官方一手数据 | 国家统计局、央行、证监会/交易所、政府部门、行业协会、官方行业协会统计、公司官方财报/公告/官网 |
| **B 级** | 权威媒体 | 新华社、人民日报、央视、路透、彭博、FT、WSJ、财新、第一财经、证券时报、上证报、中国证券报、经济观察报、晚点、36氪（仅深度报道栏目）等主流专业媒体 |
| **B 级** | 权威券商研报 | 见下方「券商白名单」 |
| **B 级** | 权威咨询/研究机构 | 见下方「咨询机构白名单」 |
| **✗ 排除** | 一律不得引用 | 自媒体/营销号、匿名博客、低质聚合站（如百家号/UC 号/趣头条等无编辑审核源）、无出处二手转述、个人观点贴、AI 生成内容聚合站 |

例外：若某主题实在缺少 A/B 级来源，宁可标注「数据缺口」并说明，也不得用低质量来源充数。

## 四、使用规则

1. **动态更新**：券商分类评级每年更新；执行时先检索当年最新评级结果确认名单，再开始检索。
2. **同一数据 ≥2 个 A/B 级来源交叉验证**；无法交叉验证的数据在报告中标记「单一来源」。
3. **来源冲突**：不同权威来源数据矛盾时，在正文标注「来源分歧」，并列明双方口径，不作强行统一。
4. **引用可追溯**：证据库中每条来源记录媒体/机构名、发布日期、可信级别、URL，缺失任何一项视为不可用证据。

## 五、排除清单（示例，防误用）

- 自媒体与营销号（微信公众号个人号、百家号、网易号、UC 号、头条号等无编辑审核账号）
- 匿名博客 / 个人技术博客（无机构背书）
- 低质聚合站（无一手来源的转载聚合）
- 无出处的二手转述（"有分析称""市场普遍认为"而无具体来源）
- 券商/咨询公司之外的未授权第三方数据帖

> `scripts/build_report.py --lint` 内置域名黑名单，构建时会自动拦截上表中的低质域名（baijiahao、toutiao、uc.cn、360kuai 等）并对需人工确认的域名（搜狐、网易、知乎、雪球、CSDN 等）给出 WARN。

## 六、付费墙内容处理规则

Yole Group、LightCounting、Gartner、Bloomberg NEF 等机构的核心数据通常位于付费墙后。处理规则：

1. **可引用其公开部分**：新闻稿、公开摘要、白皮书的免费章节、会议演讲稿、被权威媒体转述的结论——可作为 B 级来源引用，并在证据库中注明「付费报告公开摘要」。
2. **不得编造具体数字**：未获取原文时，禁止推测或补写付费内容中的具体数值、份额、预测。
3. **口径必须转述**：引用时写明「据 XX 机构公开摘要显示」，不得伪装成完整报告结论。
4. **付费墙即数据缺口**：若某关键判断只有付费来源支撑，按「数据缺口」处理——标注「该数据仅见于付费来源，未获授权核实」，并优先寻找 A 级官方数据替代。

## 七、预留：本地一手资料通道（暂不启用）

> **状态：预留，待本地数据库建成后启用。当前阶段一律按「网络公开信源」单通道执行。**

后续接入时计划新增：

- **A+ 级（最高）**：本地一手文件——企业财报原件、公告 PDF、公司官网原始披露、自有数据库中经三重校验的记录、本地专利导出数据。
- 阶段 0 增加一步「本地资料盘点」：先 Glob/查询本地目录与数据库，把既有的一手证据纳入证据库，网络检索预算优先补本地缺口。
- 本地来源著录时须写明文件具体出处（文件名 + 页码/表号），便于回溯核对。

启用此通道前，不得在报告中使用未经本白名单登记的数据源。
