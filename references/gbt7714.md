# GB/T 7714-2015 参考文献著录格式速查

本文件规定 storm-report 报告的引用规则：**正文上标角标 [n]（顺序编码制）+ 文末参考文献表（GB/T 7714-2015）**。

## 一、正文角标规则

- 引用处紧跟句末加**上标角标**：`[1]`、`[2,3]`、`[4-6]`。
- 编号按**首次出现顺序**递增，全文唯一。
- 一条引文可能带多个文献编号时用逗号或范围连接，如 `[3,7]`、`[8-10]`。
- 角标位于标点符号（句号、逗号）**之前**或紧跟其后的具体主张之后（行业惯例：置于所引内容之后、句号之前）。
- 示例正文表述：全球光模块市场规模在 2025 年达到约 XXX 亿美元[1]。

## 二、文末参考文献表格式（GB/T 7714-2015）

参考文献表置于文末，按正文引用顺序编号，每条以 `[n]` 开头。以下为 storm-report 最常用类型模板：

### 1. 电子/网络文献（最常见，EB/OL）

```
[序号] 作者. 题名[EB/OL]. (发布日期/更新日期)[引用日期]. URL.
```

示例：

```
[1] 中国光通信产业发展白皮书[EB/OL]. (2025-06-30)[2026-08-26]. https://example.gov.cn/xxx.
[2] Reuters. Global optical module market to grow 18% in 2026[EB/OL]. (2026-03-15)[2026-08-26]. https://www.reuters.com/xxx.
```

### 2. 报纸文章（N）

```
[序号] 作者. 题名[N]. 报纸名, 出版日期(版次).
```

示例：

```
[3] 程丹. 证券公司2025年分类评价结果出炉[N]. 证券时报, 2025-09-29(A02).
```

### 3. 期刊论文（J）

```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

示例：

```
[4] 张三, 李四. 高速光互联技术演进[J]. 光通信研究, 2024, 50(3): 12-20.
```

### 4. 专著/报告（M / R）

```
[序号] 作者. 书名[M]. 版本. 出版地: 出版社, 出版年: 页码.
[序号] 机构. 报告名[R]. 出版地: 机构名, 出版年.
```

### 5. 官方公告/财报（EB/OL 或 R）

公司财务数据、监管公告统一按电子文献或报告类著录，并在题名中体现「年报/公告」字样：

```
[5] 中兴通讯股份有限公司. 2025年年度报告[EB/OL]. (2026-03-27)[2026-08-26]. https://www.szse.cn/xxx.
```

## 三、编号锁定规则（storm-report 增强，最高优先级）

**每条来源在阶段 4 进入证据库时即分配固定 `[n]`，按入库顺序递增，此后不得重排、不得回收。**

- 阶段 5 写作**只复用**证据库中已有的 `[n]`，禁止在写作时新增或重新编号。
- 确需新增来源时，追加在末尾（当前最大编号 +1），并同步补入证据库。
- 被删除的来源编号**不回收**，标记为「已弃用」并保留占位，避免后续引用整体错位。
- 目的：把断号与错位问题在源头消灭，而不是留到阶段 6 靠人工返工核对。

## 四、作者与机构著录规则

- **中文文献**：姓在前，名在后，多位作者用逗号分隔，3 个以上只著录前 3 位后加「, 等」（英文加 "et al."）。
- **机构作者**：使用机构全称（如「中国信息通信研究院」），不用简称。
- **无作者**：以题名开头（如示例 [1]）。
- **英文文献**：作者姓在前、名缩写在后，如 `Reuters` 即机构名；个人作者如 `Smith J, Lee K.`。

## 五、可信级别标注

在 HTML 报告的参考文献表每条末尾追加级别徽标（**不属于 GB/T 7714 格式本身，属于 storm-report 增强**）：

```
[1] … 网址. [A级]
[3] 程丹. … 证券时报, 2025-09-29(A02). [B级]
```

级别定义见 `references/source-whitelist.md`。

## 六、常见错误自查

- ✗ 正文编号与文末表不对应 / 跳号 → 必须逐一核对
- ✗ 引用无 URL（EB/OL 必须给访问网址）
- ✗ 网络文献缺引用日期 → 必填，格式 [YYYY-MM-DD]
- ✗ 把「转引自」来源当作一手来源 → 返查原始出处
- ✗ 白名单外来源进入参考文献 → 删除
- ✗ 写作阶段重新编号 / 删除条目后回收编号 → 违反编号锁定规则，回到证据库修正
- ✗ 手工核对断号 → 用 `build_report.py --lint` 自动校验，ERROR 清零后再构建 HTML
